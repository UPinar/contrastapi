Use Cases

Scan dependencies for CVEs

POST /v1/check/dependencies — find exploited vulns, EPSS exploit probability, and CISA KEV status across your package.json, requirements.txt, or go.sum. Bulk endpoint supports 10 (free) or 50 (Pro) items per request.

Audit a domain in one call

GET /v1/audit/{domain} — full audit in a single request: SSL grade, DNS hygiene, tech fingerprint, email security (SPF/DMARC/DKIM), live security headers. Runs 8+ checks in parallel; typically under 3 seconds on a warm cache.

Triage threat intel with an AI agent

Point Claude Desktop at the MCP server and ask: "Is this IOC malicious? Check AbuseIPDB, Shodan, URLhaus, and MalwareBazaar." The agent chains the lookups automatically — you get a structured summary, not a wall of raw JSON.

PR-time security checks in CI

POST /v1/check/secrets + /v1/check/injection in your CI pipeline — block PRs that introduce hardcoded credentials, SQL/command injection patterns, or ReDoS-prone regexes. No API key required.

FAQ

Do I need an API key?
No. The free tier works without authentication — just send requests. Pro users include their key via the Authorization: Bearer header.
What happens when I hit the rate limit?
You'll get a 429 response with a RateLimit-Reset header showing when your limit resets. Upgrade to Pro for 10x the limit.
How do I get my API key after purchase?
After checkout, you'll be redirected to a welcome page showing your key. Save it immediately — it's shown only once.
Can I cancel anytime?
Yes. Cancel through Lemon Squeezy customer portal. Your key stays active until the billing period ends.
Is there an SLA?
The API targets 99.9% uptime. Check /v1/status for real-time health. Pro users get priority support via email.

Data Freshness

Threat intelligence data (IP reputation, Shodan, AbuseIPDB) is cached for 24 hours per query. CVE/EPSS data syncs every 2 hours. For real-time results, use unique queries.
