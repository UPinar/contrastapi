FAQ

Do I need an API key?
No. The free tier works without authentication — just send requests. Pro users include their key via the Authorization: Bearer header.
What happens when I hit the rate limit?
You'll get a 429 response with a RateLimit-Reset header showing when your limit resets. Upgrade to Pro for 10x the limit.
How do I get my API key after purchase?
After checkout, you'll be redirected to a welcome page showing your key. Save it immediately — it's shown only once.
Can I cancel anytime?
Yes. Cancel through Lemon Squeezy customer portal. Your key stays active until the billing period ends.
Is there an SLA?
The API targets 99.9% uptime. Check /v1/status for real-time health. Pro users get priority support via email.

Data Freshness

Threat intelligence data (IP reputation, Shodan, AbuseIPDB) is cached for 24 hours per query. CVE/EPSS data syncs every 2 hours. For real-time results, use unique queries.
