网站情报

单页面审计，明确的伦理底线：每目标 eTLD+1 限速（60/分钟）、自我标识 UA、遵守 robots.txt、尊重 Cache-Control、不进行 SMTP 探测。

GET /v1/robots/{domain} 解析 robots.txt — sitemaps、按 UA 的 allow/disallow、crawl-delay（RFC 9309）
GET /v1/redirect/{url:path} 逐跳跟踪 URL 重定向链，每跳 SSRF 防护
GET /v1/email/verify/{email} 邮箱综合校验：语法 + MX + 一次性 + 角色 + 免费提供商（不进行 SMTP 探测）
GET /v1/brand/{domain} 从首页 <head> 抓取公开品牌资源：favicon、og:image、theme-color、JSON-LD logo
GET /v1/seo/{domain} 单页 SEO 审计 + 0-100 综合分数（10 项规则）+ 具体的 missing_signals

常见问题

需要 API 密钥吗？
不需要。免费版无需认证，直接发送请求即可。Pro 用户通过 Authorization: Bearer 头部携带密钥。
达到速率限制后会怎样？
您会收到 429 响应，其中 RateLimit-Reset 头部显示限制重置时间。升级 Pro 版可获得 10 倍限额。
购买后如何获取 API 密钥？
完成支付后，您将被重定向到欢迎页面，显示您的密钥。请立即保存——密钥仅显示一次。
可以随时取消吗？
可以。通过 Lemon Squeezy 客户门户取消。密钥在计费周期结束前保持有效。
有 SLA 吗？
API 目标可用性为 99.9%。访问 /v1/status 查看实时健康状态。Pro 用户可通过邮件获得优先支持。
中国大陆可以访问吗？
可以。API 服务器位于欧洲，中国大陆可直接访问，无需 VPN。典型延迟约 250-350ms，适合大多数使用场景。

数据新鲜度

  • 域名与 IP 查询：每次查询缓存 1 小时。
  • IP 威胁情报源：FireHOL 每 6 小时刷新；Tor 出口列表、Feodo C2、云 IP 段每 1 小时刷新。
  • Web 情报（robots.txt、品牌资产）：每个目标缓存 1 小时。
  • Wayback 历史：缓存 24 小时（上游变动较少）。
  • CVE / EPSS / KEV：通过 cron 从 NVD、MITRE、FIRST EPSS 和 CISA KEV 同步（典型延迟 <2 小时）。
  • 每目标节流：web 情报端点上每个可注册域名（eTLD+1）每分钟 60 请求 —— 保护上游源免受您的突发请求冲击。
  • 如需实时结果，请改变查询（缓存按目标精确匹配）。
