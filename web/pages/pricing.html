FAQ

Is the Free tier really free?
Yes. @@RL_ANON_CREDIT_LIMIT@@ credits/hour per IPv4 address or IPv6 /64. Every endpoint and every MCP tool is open to all callers, except monitoring (the watchlist tools), which needs an API key. Pro also raises the hourly credit budget.
What's actually behind the API?
Security data in one API: CVEs (EPSS, CISA KEV, risk scores, affected products), public exploits, open-source package advisories, vulnerable Windows drivers, domains (DNS, subdomain takeover, email authentication, email address checks, TLS, security headers, RDAP/WHOIS, Wayback Machine captures, subdomains, certificates), IP addresses and autonomous systems, CWE, CVSS vectors and D3FEND, breached passwords and image metadata. A Pro key adds monitoring of CVEs, products, CVE searches, packages, domains and IP addresses. Every endpoint but /image_inspect is also an MCP tool. See every endpoint.
How do I use this with Claude / Cursor / an MCP client?
See the MCP setup guide. One JSON config, streamable-http transport, no key required for the Free tier.
How do I check that the API is up?
Real-time health is reported at /health, with the sync state of each data feed. It costs no credit.
Can I pay per call without a key?
Yes, on the endpoints and MCP tools that take payment. See the API documentation. When the free credits of a request without a key are spent, a REST endpoint answers 402 with the price, and an MCP tool call gets a tool result that holds the price. One credit costs $@@PRICING_X402_USD_PER_CREDIT@@, paid in USDC on Solana with x402. A REST call is charged only when it answers 200. An MCP call is charged only when its tool result is served.
