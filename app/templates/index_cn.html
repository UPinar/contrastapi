使用场景

扫描依赖项中的 CVE

POST /v1/check/dependencies — 在 package.json、requirements.txt 或 go.sum 中查找已被利用的漏洞、EPSS 利用概率以及 CISA KEV 状态。批量接口支持每请求 10 个（免费）或 50 个（Pro）。

一次调用审计域名

GET /v1/audit/{domain} — 单次请求完成全面审计：SSL 评级、DNS 健康状况、技术栈识别、邮件安全（SPF/DMARC/DKIM）、实时安全响应头。通过 C 扫描器实现 2 秒内响应。

用 AI 智能体分流威胁情报

将 Claude Desktop 指向 MCP 服务器后提问："这个 IOC 是恶意的吗？查一下 AbuseIPDB、Shodan、URLhaus 和 MalwareBazaar。" 智能体会自动串联查询，返回结构化摘要而非原始 JSON。

CI 流水线中的 PR 安全检查

在 CI 中调用 POST /v1/check/secrets + /v1/check/injection — 拦截引入硬编码凭据、SQL/命令注入模式或 ReDoS 正则的 PR。无需 API 密钥。

常见问题

需要 API 密钥吗？
不需要。免费版无需认证，直接发送请求即可。Pro 用户通过 Authorization: Bearer 头部携带密钥。
达到速率限制后会怎样？
您会收到 429 响应，其中 RateLimit-Reset 头部显示限制重置时间。升级 Pro 版可获得 10 倍限额。
购买后如何获取 API 密钥？
完成支付后，您将被重定向到欢迎页面，显示您的密钥。请立即保存——密钥仅显示一次。
可以随时取消吗？
可以。通过 Lemon Squeezy 客户门户取消。密钥在计费周期结束前保持有效。
有 SLA 吗？
API 目标可用性为 99.9%。访问 /v1/status 查看实时健康状态。Pro 用户可通过邮件获得优先支持。
中国大陆可以访问吗？
可以。API 服务器位于欧洲，中国大陆可直接访问，无需 VPN。典型延迟约 250-350ms，适合大多数使用场景。

数据新鲜度

威胁情报数据（IP 信誉、Shodan、AbuseIPDB）每次查询缓存 24 小时。CVE/EPSS 数据每 2 小时同步一次。如需实时结果，请使用不同的查询。
