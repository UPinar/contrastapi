IP & ASN Intelligence API with Monitoring

Look up a public IP address or an autonomous system. The answer names the AS, the country, the cloud or CDN range and whether the address is a Tor exit. The tools are free without an API key and work over REST and as MCP tools, for developers and AI agents.

What you can ask

GET /ip_lookup/{ip_address} MCP ip_lookup. The AS, country, cloud or CDN range, Tor exit status, DROP listing and PTR name of a public IP address. A Pro caller fills the Shodan and AbuseIPDB slots with its own key. API docs
GET /asn_lookup/{target} MCP asn_lookup. An autonomous system by AS number or by an address it holds: name, country and prefixes. API docs

Example

bashcurl https://api.contrastcyber.com/ip_lookup/8.8.8.8

Monitor it

A Pro key can watch public IP addresses, one address per item. Add an item with watchlist_edit. Then read its change events with watchlist_events. You pull the events when you want them.

An IP item names one address and makes no request to it. The server compares the address with its local lists about every 15 minutes, after one of the lists is updated. An event says when the address lands on the DROP list, when it leaves the list, and when its hosting changes, such as from one AS to a cloud range. The hosting event comes when the new class is seen again after both hosting lists were updated. A DROP event also carries the date and the copyright text of the list. They stay with the data, as the list asks.

  • Shodan and AbuseIPDB: asked live, only for a Pro key that saved its own Shodan or AbuseIPDB key at vendor keys. They fill the internet_exposure and reputation members.

FAQ

Does it support IPv6?
Yes. ip_lookup and asn_lookup take public IPv4 and IPv6 addresses.
Can I tell if an IP is a Tor exit or a cloud address?
Yes. ip_lookup returns is_tor_exit, and the cloud provider, the service and is_cdn when a published range holds the address.
Are the AS prefixes the same as BGP announcements?
Not always. asn_lookup derives its prefixes from IPtoASN ranges, so they can differ from what the AS announces in BGP.
Does it need an API key?
No. Both tools work without a key, within the hourly credit limit.
